Análisis de correspondencia

Contenido ya estudiado en el curso Contenido nuevo y su función
Estructura básica HTML: <!DOCTYPE html>, <html>, <head>, <body>, <meta charset>, <title>, <link> Variables CSS (:root, var()): permiten guardar valores (como los colores de marca) una sola vez y reutilizarlos en toda la hoja de estilos sin repetirlos.
Etiquetas semánticas HTML5: <header>, <nav>, <section>, <footer> box-sizing: border-box: hace que el padding y el borde se incluyan dentro del ancho definido de un elemento, evitando que se desborde.
Elementos de texto, imágenes y listas: <h1> a <h4>, <p>, <a>, <ul>, <li>, <img>, <strong> Flexbox (display: flex, justify-content, align-items, gap): sistema de maquetado que alinea y distribuye elementos en una fila o columna de forma flexible.
Selectores CSS: universal (*), de etiqueta, de clase (.), de id (#), y pseudo-clase :hover CSS Grid (display: grid, grid-template-columns, repeat(), minmax(), auto-fit): sistema de maquetado en cuadrícula, ideal para alinear tarjetas en columnas que se ajustan solas.
Fondos y tipografía CSS: background-color, background-image, background-position, color, font-family, font-size, font-weight, text-align, text-decoration, text-transform, line-height Posicionamiento (position: sticky / relative / absolute, z-index): controla dónde se ubica un elemento en la pantalla, por ejemplo para fijar el menú al hacer scroll o superponer capas.
Modelo de caja CSS: margin, padding, width, max-width, border-radius background-size: cover: hace que una imagen de fondo cubra todo el espacio disponible sin deformarse.
Color con transparencia: rgba() box-shadow: agrega una sombra alrededor de un elemento para dar sensación de profundidad.
Comentarios CSS: /* ... */ transition + transform: translateY(): anima de forma suave un cambio de estilo, como el efecto de "elevación" de una tarjeta al pasar el mouse.
object-fit: cover: recorta una imagen para que llene su contenedor sin estirarse ni deformarse.
text-shadow: agrega sombra al texto para mejorar su lectura sobre fondos con imagen.
@media (max-width: ...): media query que aplica estilos distintos según el tamaño de pantalla, base del diseño responsivo.
<iframe>: incrusta contenido de otra página (como un mapa de Google Maps) dentro del documento HTML.
letter-spacing: ajusta el espacio horizontal entre letras de un texto.
